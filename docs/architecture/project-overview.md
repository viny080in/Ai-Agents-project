# Azure AI Agent Workflow Automation

## Project 1: Azure Cloud Operations Agent

### Objective
An AI-powered operations assistant that monitors simulated Azure infrastructure,
analyzes telemetry, identifies operational issues and recommends remediation.

### Azure concepts demonstrated
- Azure Monitor
- Log Analytics
- Azure Resource Manager
- Azure Functions
- Azure AI Foundry
- Managed Identity
- Role-Based Access Control

### Local implementation
- Python agent
- Docker containers
- Simulated Azure resources
- Synthetic infrastructure telemetry
- Local operational tools
- Human approval for remediation

## Project 2: Azure Incident Management Agent

### Objective
An AI-powered incident management assistant that detects incidents,
analyzes root causes, classifies severity and coordinates remediation workflows.

### Azure concepts demonstrated
- Azure Monitor Alerts
- Application Insights
- Log Analytics and KQL
- Azure Service Bus
- Logic Apps
- Azure Functions
- Microsoft Entra ID
- Azure Automation

### Local implementation
- Python agent
- Docker containers
- Synthetic incident events
- Simulated alert processing
- Incident classification
- Root cause analysis
- Human-approved remediation

## Shared Architecture

Both projects will use:
- Python
- Docker Compose
- REST APIs
- Local workflow orchestration
- Structured logging
- GitHub documentation

## Cloud Access Restrictions

No Azure subscription, Azure Portal or Azure DevOps access is required.

Azure services are simulated locally. No claim of actual Azure deployment
or integration will be made.
